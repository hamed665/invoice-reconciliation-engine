Compare two CSV files

Exact headers: id, tenant, currency, reference, amount, date. Dates: YYYY-MM-DD. Currencies: USD, EUR, OMR. Up to 200 rows / 128 KB per file.

The public portfolio deployment is sample-only. Private local mode supports CSV processing without persistent storage.

Matching rules
  • Exact amount with currency-specific decimal precision
  • Same workspace, currency and normalized reference
  • Payment date within the selected window
  • Unique one-to-one invoice/payment relationship
